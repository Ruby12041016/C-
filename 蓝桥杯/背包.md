# 背包问题

## 基本概念
**背包容量 W**，**n 个物品**，每个物品有：
- 重量/体积 w[i]
- 价值 v[i]
- 数量 s[i]（0-1背包：s[i]=1；完全背包：s[i]=∞；多重背包：s[i]=k）

目标：在不超过背包容量的情况下，最大化总价值。

---

## 1. 0-1背包（最基础）

### 特点
每个物品要么选（1个），要么不选（0个）

### 核心思想
用 `dp[j]` 表示容量为 j 时的最大价值

**状态转移方程**：
`dp[j] = max(dp[j], dp[j-w[i]] + v[i])`

### 为什么必须逆序？
举个例子：
- 物品：重量3，价值5
- 背包容量：6

如果**正序**更新（j从小到大）：
```
初始：dp[0]=0, dp[1]=0, ..., dp[6]=0
j=3: dp[3] = max(dp[3]=0, dp[0]+5=5) → dp[3]=5
j=6: dp[6] = max(dp[6]=0, dp[3]+5=5+5=10) → dp[6]=10
看起来正确，但...
```
**问题来了**：当物品重量小于容量一半时
```
物品：重量2，价值3
j=2: dp[2] = max(0, dp[0]+3=3) → dp[2]=3
j=4: dp[4] = max(0, dp[2]+3=3+3=6) → dp[4]=6
```
这里 j=4 用了 dp[2]，而 dp[2] 已经包含了这个物品（价值3），
所以 dp[4]=6 相当于放了**2个**该物品！这就不符合0-1背包了。

**逆序更新**（j从大到小）：
```
j=6: dp[6] = max(0, dp[4]+3) 但此时 dp[4] 还没更新，是0 → dp[6]=3
j=4: dp[4] = max(0, dp[2]+3) 此时 dp[2]=3 → dp[4]=6
j=2: dp[2] = max(0, dp[0]+3=3) → dp[2]=3
```
这样每个物品只会用一次。

### 代码模板
```cpp
int dp[W+1] = {0};
for(int i=0; i<n; i++) {
    for(int j=W; j>=w[i]; j--) {  // 关键：逆序
        dp[j] = max(dp[j], dp[j-w[i]] + v[i]);
    }
}
cout << dp[W];
```

## 2. 完全背包

### 特点
每种物品可以选无限个

### 为什么必须正序？
用上面的例子：
物品：重量2，价值3

**正序更新**：
```
j=2: dp[2] = max(0, dp[0]+3=3) → dp[2]=3
j=4: dp[4] = max(0, dp[2]+3=3+3=6) → dp[4]=6
j=6: dp[6] = max(0, dp[4]+3=6+3=9) → dp[6]=9
```
j=4 时用了更新过的 dp[2]，相当于可以放多个相同的物品，这**正是我们想要的**。

### 代码模板
```cpp
int dp[W+1] = {0};
for(int i=0; i<n; i++) {
    for(int j=w[i]; j<=W; j++) {  // 关键：正序
        dp[j] = max(dp[j], dp[j-w[i]] + v[i]);
    }
}
cout << dp[W];
```

## 3. 多重背包

### 特点
第 i 种物品最多选 s[i] 个

### 解决方法：二进制拆分
把数量 s 拆成 1, 2, 4, 8, ... 2^k, 剩余
比如 s=13 → 拆成 1, 2, 4, 6
拆完后每个"新物品"做0-1背包

**为什么二进制拆分？**
因为1,2,4,...,2^k 可以组合出 0~2^(k+1)-1 的所有数
比如 1,2,4 可以组合出 0~7
再加上剩余的数，就可以组合出 0~s 的所有数

### 代码模板
```cpp
int dp[W+1] = {0};
vector<pair<int, int>> items;  // (重量, 价值)

// 二进制拆分
for(int i=0; i<n; i++) {
    int k = 1;
    while(k <= s[i]) {
        items.push_back({w[i]*k, v[i]*k});
        s[i] -= k;
        k *= 2;
    }
    if(s[i] > 0) {
        items.push_back({w[i]*s[i], v[i]*s[i]});
    }
}

// 0-1背包
for(auto [weight, value] : items) {
    for(int j=W; j>=weight; j--) {
        dp[j] = max(dp[j], dp[j-weight] + value);
    }
}
cout << dp[W];
```

## 4. 混合背包

### 特点
物品类型混合：有的是0-1，有的是完全，有的是多重

### 处理方法
```cpp
for(每个物品) {
    if(是完全背包) {
        for(j=w[i]; j<=W; j++)  // 正序
            dp[j] = max(dp[j], dp[j-w[i]]+v[i]);
    }
    else if(是0-1背包) {
        for(j=W; j>=w[i]; j--)  // 逆序
            dp[j] = max(dp[j], dp[j-w[i]]+v[i]);
    }
    else { // 多重背包
        二进制拆分后做0-1背包
    }
}
```

## 5. 二维费用背包

### 特点
有两个限制条件，比如重量限制 W 和体积限制 V

### 状态表示
`dp[j][k]` 表示重量不超过 j，体积不超过 k 时的最大价值

### 代码模板
```cpp
int dp[W+1][V+1] = {0};
for(int i=0; i<n; i++) {
    for(int j=W; j>=w[i]; j--) {      // 重量逆序
        for(int k=V; k>=v[i]; k--) {  // 体积逆序
            dp[j][k] = max(dp[j][k], dp[j-w[i]][k-v[i]] + val[i]);
        }
    }
}
cout << dp[W][V];
```

## 6. 分组背包

### 特点
物品分成若干组，每组内物品互斥，最多选一个

### 三重循环顺序
1. 遍历所有组
2. 遍历容量（逆序）
3. 遍历组内物品

```cpp
int dp[W+1] = {0};
for(int g=0; g<group_num; g++) {      // 遍历组
    for(int j=W; j>=0; j--) {         // 逆序容量
        for(int i=0; i<group[g].size(); i++) {  // 遍历组内物品
            int w = group[g][i].w;
            int v = group[g][i].v;
            if(j >= w) {
                dp[j] = max(dp[j], dp[j-w] + v);
            }
        }
    }
}
```

**为什么容量循环在最外层不行？**
因为这样会从不同组选多个物品，违反了"每组只能选一个"的规则。

## 7. 求方案数

### 初始化和转移不同
```cpp
int dp[W+1] = {0};
int count[W+1] = {0};
count[0] = 1;  // 容量为0有1种方案：什么都不选

for(int i=0; i<n; i++) {
    for(int j=W; j>=w[i]; j--) {
        if(dp[j] < dp[j-w[i]] + v[i]) {
            dp[j] = dp[j-w[i]] + v[i];
            count[j] = count[j-w[i]];  // 新方案
        }
        else if(dp[j] == dp[j-w[i]] + v[i]) {
            count[j] += count[j-w[i]];  // 方案数增加
        }
    }
}
```

## 8. 求具体方案

### 记录选择
```cpp
int dp[W+1] = {0};
int path[n+1][W+1] = {0};  // path[i][j]表示容量j时是否选了物品i

for(int i=1; i<=n; i++) {
    for(int j=W; j>=w[i]; j--) {
        if(dp[j] < dp[j-w[i]] + v[i]) {
            dp[j] = dp[j-w[i]] + v[i];
            path[i][j] = 1;  // 选了物品i
        }
    }
}

// 输出方案：倒推
int j = W;
for(int i=n; i>=1; i--) {
    if(path[i][j]) {
        cout << i << " ";  // 选了物品i
        j -= w[i];
    }
}
```

## 记忆技巧

| 维度 | 顺序 | 说明 |
|------|------|------|
| 0-1背包 | 一维逆序 | 防止重复使用 |
| 完全背包 | 一维正序 | 允许重复使用 |
| 多重背包 | 拆分成0-1 | 二进制优化 |
| 分组背包 | 组内逆序 | 每组只能选一个 |
| 二维费用 | 二维逆序 | 两个限制条件 |

**简单判断方法**：
- 如果物品**只能选一次**：容量逆序
- 如果物品**能选多次**：容量正序
- 如果物品**有数量限制**：拆分成0-1背包
- 如果物品**分组互斥**：先组后容量再物品

## 实际例子对比

**题目**：W=10
物品1：重量3，价值5
物品2：重量4，价值6
物品3：重量2，价值3

### 0-1背包结果：
只能选一种组合，比如：
- 物品1+物品2：重量7，价值11
- 物品1+物品3+物品3：不行，只能选1个物品3

### 完全背包结果：
可以重复选，比如：
- 物品3×5个：重量10，价值15
- 物品1×2+物品3×2：重量10，价值16

### 多重背包（物品3最多2个）结果：
- 物品1×2+物品3×2：重量10，价值16
- 物品2×2+物品3：重量10，价值15
